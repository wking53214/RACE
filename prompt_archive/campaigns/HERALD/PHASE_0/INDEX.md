# HERALD PHASE_0 PROMPT ARCHIVE

Store each generated PHASE_0 prompt in its own immutable version directory.

Each prompt version directory must contain:

- PROMPT.md — exact generated prompt.
- RECORD.md — generation and execution context.
- EVALUATION.md — completed only after actual execution.

Use the campaign-phase-sequence-version naming convention.

## Version Register

| Prompt ID | Purpose | Status |
|---|---|---|
| HERALD-P0-001-v1 | Initial RACE Phase 0 discovery, red-team investigation, and blueprint prompt | GENERATED — NOT EXECUTED |

This register identifies an archived prompt candidate, not a completed HERALD campaign.

## Archive Rules

- Never overwrite an archived prompt version.
- A substantive revision creates a new version directory.
- Do not create an execution evaluation until the corresponding prompt has actually been executed.
- Preserve the exact prompt and its generation record.
- Do not invent historical prompt versions or results.
