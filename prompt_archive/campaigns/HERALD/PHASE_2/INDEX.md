# HERALD PHASE 2 PROMPT ARCHIVE

Store each generated PHASE_2 prompt in its own immutable version directory.

Each prompt version directory contains:

- PROMPT.md — exact generated prompt.
- RECORD.md — generation and authorization context.
- EVALUATION.md — completed only after actual execution.

Use the campaign-phase-sequence-version naming convention.

## Version Register

| Prompt ID | Purpose | Status |
|---|---|---|
| HERALD-P2-001-v1 | Approved implementation, downstream integration, and adversarial closure | GENERATED — NOT EXECUTED |

This register identifies an archived prompt candidate, not an authorized or completed HERALD implementation campaign.

## Archive Rules

- Never overwrite an archived prompt version.
- A substantive revision creates a new version directory.
- Phase 2 execution requires complete Phase 1 outputs and explicit human authorization.
- Do not create execution evaluations until the corresponding prompt has actually been executed.
- Preserve the exact prompt and its generation record.
