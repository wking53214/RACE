# HERALD PROMPT ARCHIVE

This directory preserves the prompts generated and evaluated during the HERALD campaign.

Each phase has its own directory.

Each generated prompt version receives a unique directory containing:

- PROMPT.md
- RECORD.md
- EVALUATION.md

## Prompt Identification

HERALD-P0-001-v1
HERALD-P1-001-v1
HERALD-P2-001-v1

These are naming examples, not records of prompts already generated.

## Campaign Rule

Do not create an execution evaluation until the corresponding prompt has actually been executed.

Do not invent historical prompt versions or results.
