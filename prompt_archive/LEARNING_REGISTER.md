# RACE LEARNING REGISTER

## 1. Purpose

Provide a central index of lessons derived from prompt generation and execution.

## 2. Learning Categories

- Prompt clarity.
- Mission alignment.
- Expert panel effectiveness.
- Evidence quality.
- Adversarial effectiveness.
- Technical completeness.
- Authorization compliance.
- Output quality.
- Phase handoffs.
- Efficiency and unnecessary complexity.
- Repeatability.

## 3. Learning Status

- OBSERVED
- UNDER_REVIEW
- ACCEPTED
- REJECTED
- DEFERRED
- IMPLEMENTED
- VALIDATED

## 4. Required Learning References

Every entry must identify:

- Learning identifier.
- Source campaign.
- Source prompt identifiers.
- Supporting evaluation.
- Evidence references.
- Description of the observation.
- Impact.
- Recommended improvement.
- Current disposition.
- Approval reference, if applicable.
- Validation reference, if implemented.

## 5. Register

Add one entry per learning identifier.

Do not combine unrelated observations into one entry.

## 6. Governing Rule

The register records lessons; it does not independently authorize changes to RACE.
