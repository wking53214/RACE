# RACE EVIDENCE PROTOCOL
Version: 1.0

## 1. Purpose

Establish consistent rules for collecting, evaluating, recording, and reporting evidence during every RACE mission.

## 2. Evidence Classification

Every material claim must be distinguishable as one of the following:

- EXECUTED: An action demonstrably performed, with an identifiable execution record.
- INSPECTED: An artifact, source, record, or system directly examined.
- INFERRED: A conclusion derived from identified evidence.
- UNKNOWN: A fact that has not been established.

These classifications must not be used interchangeably.

## 3. Evidence Requirements

Material findings should identify:

- Evidence identifier.
- Source.
- Location or reference.
- Collection or inspection method.
- Relevant date or version when available.
- Observation.
- Claim supported.
- Limitations.
- Confidence assessment where appropriate.

## 4. Source Hierarchy

Evidence must be evaluated according to its relevance and reliability.

For software and technical investigations:

1. Directly observed runtime behavior.
2. Reproducible execution and test results.
3. Inspected source code and configuration.
4. Build artifacts and execution records.
5. Technical documentation.
6. Unverified descriptions or statements.

This hierarchy is contextual. A source must be evaluated for the particular claim being made.

Documentation can establish documented intent. It does not independently establish runtime behavior.

## 5. Evidence Integrity

RACE must not:

- Invent evidence.
- Fabricate test results.
- Convert assumptions into facts.
- Describe unexecuted tests as executed.
- Claim complete inspection based on partial inspection.
- Omit material contradictory evidence.
- Conceal uncertainty.

## 6. Contradictory Evidence

Conflicting evidence must be recorded.

Investigators must identify the disagreement, assess source reliability, and explain whether the conflict was resolved.

Unresolved contradictions remain open findings.

## 7. Negative Findings

A failed search or unsuccessful inspection does not automatically establish that something does not exist.

Reports must state the search scope and limitations before making absence claims.

## 8. Recommendations

Recommendations must identify their supporting evidence and distinguish factual findings from judgment.

Where evidence is insufficient, the recommendation must disclose the limitation.

## 9. Reporting Standard

Final reports must distinguish:

- Verified findings.
- Supported inferences.
- Unresolved questions.
- Known limitations.
- Unsupported claims requiring removal.

## 10. Governing Rule

No RACE conclusion may claim greater certainty than its supporting evidence permits.
